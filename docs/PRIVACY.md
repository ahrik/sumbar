# Конфиденциальность Sumbar

Актуально для версии 0.5.1. Проверено по реализации 6 ноября 2026 года.

[О программе](../README.md) · [Руководство пользователя](USER_GUIDE.md) · [Источники данных](DATA_SOURCES.md)

## Как устроена работа с данными

Sumbar работает без регистрации и учётной записи. В программе нет рекламы, аналитики, отслеживания действий и автоматической отправки отчётов об ошибках разработчикам. Программа не запрашивает банковские пароли, не подключается к счетам и не выполняет платежи или сделки.

Обработка введённых сумм и расчёты выполняются на Mac. Суммы конвертации, избранное и пороги уведомлений не отправляются поставщикам данных. Для получения котировок необходимы сетевые запросы.

## Сетевые обращения

Программа обращается напрямую к следующим источникам по HTTPS:

| Получатель | Что запрашивается |
| --- | --- |
| `cbu.uz`, при отдельных ошибках соединения — `www.cbu.uz` | Курсы валют на запрошенную ташкентскую дату |
| `finmind.uz` | Каталог бумаг и сведения о выбранной акции или облигации |
| `ru.ipakyulibank.uz` | Страница курсов Ipak Yuli Bank |
| `www.kapitalbank.uz` | Страница курсов Kapitalbank |
| `api-dbo.hamkorbank.uz` | Курсы публичного API Hamkorbank |
| `bank.uz` | Страница сравнения обменных пунктов |

Эти сайты получают IP-адрес, время и путь запроса, а также заголовки, включая обозначение Sumbar в User-Agent и условные заголовки кэша при наличии. Запрос на историческую дату содержит эту дату; запрос карточки бумаги — её тикер или ISIN. Хранение серверных журналов и дальнейшая обработка получателями определяются их собственными правилами.

Sumbar использует системный сетевой клиент macOS и обычную проверку HTTPS-сертификатов. Собственного промежуточного сервера у приложения нет. Нажатие внешней ссылки открывает сайт в браузере, где действуют его настройки и правила сайта.

## Локальное хранение

Рабочие файлы находятся в `~/Library/Application Support/Sumbar/`. В Finder выберите «Переход» → «Переход к папке» и вставьте этот путь.

| Файл или хранилище | Содержимое и срок |
| --- | --- |
| `cache.json` | Последние успешные данные источников и до 7 дней внутридневных валютных наблюдений |
| `bank-history.json` | До 31 дня успешных наблюдений банковских курсов, раздельно по банку, валюте, способу обмена и источнику |
| `currency-history.json` | Успешно запрошенные снимки ЦБ по датам; автоматический срок удаления прошлых снимков не задан |
| `alerts.json` | Правила, их пороги, состояние срабатывания и доставки, наблюдение события; сохраняются между запусками |
| macOS UserDefaults | Избранное, выбранные показатели, интервал обновления, клавиша, язык и тема; сохраняются между запусками |

Sumbar не добавляет отдельное шифрование этих файлов. Доступ к ним зависит от защиты вашей учётной записи и диска macOS; они могут попадать в ваши системные резервные копии. Резервное копирование и синхронизация средствами самой Sumbar не реализованы.

## Разрешения macOS

Разрешение уведомлений запрашивается при добавлении правила или тестировании доставки. Локальное уведомление содержит валюту, курс, источник и время проверки; оно может быть видно на экране блокировки в зависимости от настроек macOS. Видимость, звук и разрешение меняются в системных настройках уведомлений.

Автозапуск включается пользователем и управляется macOS. Глобальная клавиша регистрируется для вызова панели; программа не записывает набираемый текст. При нажатии копирования результат попадает в системный буфер обмена, с которым работают настройки и другие приложения вашего Mac.

## Удаление данных

Отдельные правила уведомлений и избранное можно удалить в интерфейсе. Для удаления файлов истории и кэша завершите Sumbar, затем удалите нужные файлы из `~/Library/Application Support/Sumbar/`. Удаление всей папки также удаляет сохранённые правила. При следующем запуске программа сможет создать рабочие файлы заново.

Настройки UserDefaults хранятся отдельно. У собранного `Sumbar.app` домен настроек — `uz.sumbar.desktop`; для полного сброса после завершения программы можно выполнить:

```sh
defaults delete uz.sumbar.desktop
```

Эта команда удаляет настройки, избранное и закрепления Sumbar. Уведомления в Центре уведомлений и разрешения приложения управляются отдельно средствами macOS.

Для удаления программы сначала отключите автозапуск, завершите Sumbar и переместите `Sumbar.app` в Корзину. Удаление приложения само по себе не удаляет рабочую папку, настройки, резервные копии или серверные журналы поставщиков.

При сообщении об ошибке отправляйте только необходимые сведения. Файлы правил, кэша и снимки экрана могут раскрыть ваши интересы и выбранные пороги; перед передачей удалите личные сведения.

## Сайт документации

Документация размещена на GitHub Pages, а готовые файлы — в GitHub Releases. При посещении и скачивании соединение обслуживает GitHub по своим правилам конфиденциальности. В сам сайт Sumbar не добавлены аналитика, внешние шрифты или рекламные скрипты. Поисковый запрос обрабатывается в браузере по загруженному статическому индексу и не отправляется отдельному поисковому сервису.
