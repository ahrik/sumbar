# Логотип Sumbar

![Логотип Sumbar](../branding/sumbar-logo-adaptive.svg)

Знак Sumbar — буква S из двух встречных лент, напоминающих обмен валют. Основной цвет — синий `#2467E7`, надпись на светлом фоне — тёмный `#182842`.

## Файлы для использования

- [Полный логотип SVG для светлого фона](../branding/sumbar-logo.svg).
- [Полный логотип SVG для тёмного фона](../branding/sumbar-logo-dark.svg).
- [SVG с автоматической сменой цвета надписи](../branding/sumbar-logo-adaptive.svg) для README и страниц с поддержкой светлой и тёмной темы.
- [Отдельный знак S в SVG](../branding/sumbar-mark.svg) для небольших иконок.
- [Исходный PNG на прозрачном фоне](../branding/sumbar-logo.png), 2172 × 724.

Надпись в SVG переведена в контуры: установка шрифтов не нужна. Для публикаций предпочтителен SVG; PNG подходит для сервисов, которые его не принимают. Файлы распространяются под [лицензией MIT проекта](../LICENSE).

## Размеры, фон и свободное место

Сохраняйте пропорции. Вокруг знака оставляйте свободное место не меньше четверти его высоты. Полный логотип используйте от 140 пикселей по ширине, отдельный знак — от 16 пикселей. При меньшей ширине заменяйте надпись отдельным знаком.

Светлый вариант рассчитан на белый или очень светлый фон, тёмный — на тёмную подложку. В строке меню macOS знак монохромный: система сама выбирает контрастный цвет. Иконка приложения — синий знак на светлой плитке.

## Где расположен логотип

- В README репозитория и в шапке сайта документации.
- В favicon сайта, строке меню macOS и шапке панели приложения.
- В иконке приложения и на фоне установочного DMG.

Мастер геометрии находится в `scripts/brand-assets.swift`. Команда пересоздаёт SVG в `branding/`, favicon в `web/assets/mark.svg` и нативный ресурс `Sources/Sumbar/Resources/SumbarMark.pdf`:

```sh
mkdir -p temp/module-cache
xcrun swift -module-cache-path temp/module-cache scripts/brand-assets.swift
```

После изменения мастера сохраните обновлённые файлы в Git, пересоберите приложение и сайт, проверьте светлую и тёмную темы. Размеры PNG для macOS и файл ICNS создаются из PDF при обычной сборке приложения.
