# Логотип Sumbar

[Логотип PNG](sumbar-logo.png) — горизонтальная композиция со знаком S и названием Sumbar, на прозрачном фоне.

Две встречные ленты образуют S и отсылают к обмену валют. Синий знак продолжает цветовой акцент проекта; тёмная надпись рассчитана на светлую подложку.
