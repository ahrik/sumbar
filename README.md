# Sumbar

<img src="branding/sumbar-logo-adaptive.svg" width="360" alt="Sumbar">

**Бесплатная программа для macOS: курсы валют, предложения банков и ценные бумаги Узбекистана в строке меню.**

Sumbar помогает проверить курс сума, сравнить обмен в банках, пересчитать сумму и получить уведомление о нужном курсе. Работает без регистрации, рекламы, подписки и платных функций. Исходный код и документация доступны под [лицензией MIT](LICENSE).

Текущая версия — **0.5.1**. Требуется **macOS 14 или новее**. Интерфейс — русский и узбекский (латиница), язык выбирается в настройках.

## Возможности

- **Курсы ЦБ Узбекистана.** Выбор валюты, конвертер, пересчёт на выбранную дату и графики до года.
- **Сравнение банков.** Ipak Yuli Bank, Kapitalbank и Hamkorbank напрямую, другие предложения — через Bank.uz. Покупка и продажа, наличные, приложение или банкомат при наличии данных.
- **Расчёт обмена.** Сумма в иностранной валюте, бюджет покупки в сумах или желаемая сумма продажи в сумах.
- **Уведомления.** Одноразовый сигнал при достижении порога по курсу ЦБ или выбранного банка.
- **История банков.** Наблюдения за последние 7 или 31 день, собранные на вашем Mac с момента использования программы.
- **Акции и облигации UZSE.** Поиск бумаг, сохранённые цены закрытия и дневная история через Finmind, сведения об эмитенте и расчёт сценария сделки.
- **Быстрый доступ.** Выбранный показатель в строке меню, избранное, глобальная клавиша, панель поверх других окон и автозапуск по желанию.

## Установка и первый запуск

**[Скачать готовый Sumbar.dmg](https://github.com/ahrik/sumbar/releases/latest/download/Sumbar.dmg)** · **[Сайт документации](https://ahrik.github.io/sumbar/)**

Откройте DMG и перетащите Sumbar на папку «Программы» в появившемся окне. Запустите приложение из этой папки и извлеките образ. Одна универсальная сборка подходит для Apple Silicon и Intel. Подробности первого запуска — в [инструкции установки](docs/INSTALLATION.md).

### Сборка из исходников

Нужен Xcode со Swift 6 и macOS SDK либо соответствующий набор инструментов Swift. Загрузите проект из [официального репозитория](https://github.com/ahrik/sumbar) и выполните:

```sh
git clone https://github.com/ahrik/sumbar.git
cd sumbar
bash scripts/swift.sh test
bash scripts/build-app.sh
open temp/outputs/Sumbar.app
```

Готовая программа появится в `temp/outputs/Sumbar.app`, архив — в `temp/outputs/Sumbar-macOS.zip`. Можно перенести `Sumbar.app` в папку «Программы». Сборка предназначена для архитектуры Mac, на котором запущена команда.

По умолчанию используется локальная подпись ad hoc. Публичная подпись Developer ID и нотариализация Apple пока не выполнены: при первом запуске macOS может запросить индивидуальное разрешение. Подробности — в [инструкции установки](docs/INSTALLATION.md) и [руководстве для участников](CONTRIBUTING.md).

После запуска нажмите значок Sumbar в строке меню. Отдельной иконки в Dock нет. Сочетание **⌥⌘S** открывает и скрывает панель. Звезда добавляет объект в избранное, значок закрепления рядом с курсом выбирает показатель для строки меню. Для завершения работы нажмите кнопку питания внизу панели.

## Данные и конфиденциальность

Sumbar обращается к ЦБ, Finmind и банковским источникам напрямую с вашего Mac. Избранное, правила уведомлений и история хранятся локально. В программе нет аналитики и учётных записей. Сторонние сайты при запросах получают обычные сетевые сведения, включая IP-адрес. Подробнее — в [описании конфиденциальности](docs/PRIVACY.md).

Курсы банков справочные: комиссии, наличие наличных и условия конкретного отделения могут отличаться. Цены бумаг — сохранённые цены закрытия с датой торговой сессии. Калькуляторы дают оценку; Sumbar не выполняет сделки и не подключается к банковским счетам. Обновления и уведомления работают, пока программа запущена и Mac не спит.

Права на рыночные данные определяются их источниками отдельно от лицензии программы. Условия и правила актуальности описаны в [источниках данных](docs/DATA_SOURCES.md).
